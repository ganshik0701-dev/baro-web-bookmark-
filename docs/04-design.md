### 글자 타일 팔레트

파비콘이 없을 때 쓰는 글자 타일 배경(도메인 해시로 하나를 고른다)과 로그인 화면 미리보기에 쓴다. 글자는 흰색(`#FFFFFF`), 여덟 색 모두 흰 글자와 대비 5.8:1 이상.

## 타이포그래피

| 용도 | 지정 |
| --- | --- |
| 로고·큰 제목 | Gowun Batang 700 (명조) |
| 본문 전체 | IBM Plex Sans KR 400/500/600 |
| 로그인 화면 로고 | 40px (Gowun Batang 700) |
| 로그인 화면 소개 문구 | 19px, line-height 1.55 |
| 화면 제목 | 27px |
| 섹션 제목 | 15px / 600 |
| 본문 | 14px, line-height 1.7 |
| 캡션·상태바 | 12~12.5px |

글꼴은 앱에 넣어 배포한다(`@fontsource/gowun-batang`, `@fontsource/ibm-plex-sans-kr`, 둘 다 OFL). 쓰는 굵기만 넣는다: Gowun Batang 700, IBM Plex Sans KR 400/500/600.
Google Fonts에서 불러오지 않는다. 오프라인에서도 같은 글꼴로 보이고, 켤 때 기본 글꼴에서 바뀌는 깜빡임이 없고, 실행할 때마다 외부로 요청이 가지 않게 하기 위해서다.

## 간격·모양

- 모서리: 아이콘 타일 18px, 카드 16~22px, 버튼·입력 10~13px
- 여백: 화면 좌우 28px, 카드 내부 22~24px, 요소 사이 12~16px
- 컨트롤 높이: 기본 버튼·입력 44px, 보조 버튼 38~42px
- 아이콘 타일 62px, 라벨 12.5px 한 줄 말줄임

500개 초과 시 가상 스크롤(TanStack Virtual).

## 규칙

- 파비콘 실패 시: 제목 첫 글자 + 도메인 해시로 고른 배경색 타일, 글자는 흰색
- 아이콘은 인라인 stroke SVG(굵기 1.6~1.8). 이모지 쓰지 않음
- 클릭 대상 최소 44px, 아이콘만 있는 버튼에는 `aria-label`
- 명도 대비 4.5:1 이상 (24px 이상은 3:1)
- 실제 `<button>`·`<a>`·`<input>`+`<label>` 사용. div에 onClick 금지
- 그라데이션 배경, 왼쪽 테두리 강조 카드 같은 흔한 장식은 쓰지 않는다
